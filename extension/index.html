  1. Choose Desktop, Camera, Browser tab, or Custom area.
  2. Set resolution, frame rate, audio, and output format.
  3. Click Start and grant permission to a source. For tab audio, select a browser tab and enable “Share audio”.
  4. Pause or stop using the controls. Preview and download from My captures.

MP4 is available only when your browser supports MP4 recording. Captures are stored locally, with no cloud upload or sharing service. A website cannot automatically capture an entire scrolling page or force access to another tab; those features require a browser extension. A companion extension is included in the project for full scrolling page screenshots.

For screen recording, open this app in Chrome or Edge on desktop. A browser picker is required each time. Keep the recording tab open.
